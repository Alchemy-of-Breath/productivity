# productivity
All things team productivity

## Claude Code mods

This repo is also a Claude Code plugin marketplace:

```
/plugin marketplace add Alchemy-of-Breath/productivity
```

| Mod | What it does |
|---|---|
| [northstar](mods/northstar) | Your purpose and week/month/quarter/year/5-year focus above the prompt in every session |
| [kanban](mods/kanban) | A pane with your open Monday.com tasks (read-only), plus an optional personal Day/Week board |
